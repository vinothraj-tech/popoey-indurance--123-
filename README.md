# Popoye Insurance Dashboard — Frontend Demo

A responsive admin dashboard concept based on the supplied Popoye Insurance reference. It includes the supplied logo, dashboard metrics, animated collection chart, payment-method visualization, customer/vehicle transaction table, and navigation for Customers, Payments, Policies, Transactions, Reports, and Settings.

## Files
- `index.html` — dashboard markup and modal
- `style.css` — responsive layout, visual styling, and CSS-only animation effects
- `script.js` — navigation, table filtering, demo payment-link form, toast messages, and CSV export
- `assets/popoye-logo.png` — supplied Popoye mascot logo

## Run
1. Extract the ZIP.
2. Keep `index.html`, `style.css`, `script.js`, and the `assets` folder together.
3. Double-click `index.html` to open in a browser, or use VS Code Live Server.

## Important
This is a frontend-only demo. The payment link form does not charge a customer, send a WhatsApp message, store data, or connect to a payment gateway. To make it production-ready, connect a backend, database, AiSensy API, payment gateway, authenticated admin access, and verified payment webhooks. Do not place API secrets in browser JavaScript or HTML.
